# Project 1: Interactive Sales Dashboard
## Problem: 
	This project took a pile of sales data and created something that clients and staff can look at quickly and gather the most important pieces of information. A client could also change the setting of the pivot tables and look at different data based on what information they needed. 
## Approach:
	I started with a worksheet of sales data and turned it into two pivot tables. Then I added slicers. Finally I connected the pivot tables so that when you click on a category in the slicers both pivot tables update, added charts, and three KPI cards to the project. 
## What I did:
* Created a sales data table of over 100 rows of data and named it sales.
* Built PivotTable #1 which showed revenue by region and the percents of the grand total for each category.
* Built PivotTable #2 which showed the revenue by months/quarters.
* Created slicers connected to both PivotTables
* Created charts; a column chart by region and a line chart over time.
* Created KPI cards showing total revenue, best region, and best month with the GETPIVOTDATA/INDEX-Match
## Outcome:
	At the end of the project, I had a working dashboard that showed, Total Revenue $210,000, Best Region North, and Best Month June. Along with having features so the user can click on region/product/date and watch everything update.
## What I'd do differently:
	When I first made the project I had the two pivot tables on different worksheets and that caused problems with creating a working slicer. Next time I will place the original data on one worksheet and all pivot tables, slicers, and KPI cards on one worksheet. 
## Skills demonstrated:
* PivotTables
* Date Grouping
* Slicers
* GETPIVOTDATA
*  Charts
* Conditional Formatting
* One-page dashboard layout
